# Nexo · Administración de productos

Sistema de inventario con interfaz en español, backend Express, SQLite, usuarios y pruebas Cypress.

El proyecto está en [`admin-productos`](admin-productos/README.md).

```sh
cd admin-productos
npm ci
npm start
```

Abre <http://localhost:3000> y crea tu cuenta administradora. Requiere Node.js 24 o posterior.

## Demo original

La versión original está conservada de forma independiente en [`admin-productos-demo`](admin-productos-demo/README.md).

```sh
cd admin-productos-demo
npm start
```

Abre <http://localhost:3001> con **admin / 1234**. Usa el CSV inicial y `localStorage`; ambas aplicaciones pueden ejecutarse simultáneamente.
